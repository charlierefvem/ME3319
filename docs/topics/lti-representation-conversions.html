Converting LTI System Representations

LTI Representations

The LTI state-space representation has a state equation, which describes the system dynamics,

˙𝑥–––=𝐴𝑥–––+𝐵𝑢–––,

and an output equation, which produces the outputs of interest:

𝑦–=𝐶𝑥–––+𝐷𝑢–––.

LTI systems can be represented by block diagrams, transfer functions, ordinary differential equations (ODEs), and state space.

Conversion Routes

Figure


Routes between LTI system representations.

  • ODE to transfer function: take the Laplace transform; reverse the conversion with the inverse Laplace transform.
  • ODE to state space: use one state equation for each phase variable; reverse the conversion by combining state equations algebraically.
  • ODE to block diagram: use one integrator per phase variable; reverse the conversion by manipulating the diagram into phase variables in an integrator chain.
  • State space to transfer function: use the system transfer operator. To go from a transfer function to state space, use another form first.
  • State space to block diagram: use one integrator per state equation; reverse the conversion with one state equation per integrator.
  • Transfer function to block diagram: build a chain of integrators; reverse the conversion with block-diagram algebra, including 𝐺/(1 +𝐺𝐻).

The System Transfer Operator

Take the Laplace transform of the output equation and substitute the state relation:

𝑦–(𝑡)=𝐶𝑥–––(𝑡)+𝐷𝑢–––(𝑡),L{𝑦–(𝑡)=𝐶𝑥–––(𝑡)+𝐷𝑢–––(𝑡)},𝑌–––(𝑠)=𝐶𝑋–––(𝑠)+𝐷𝑈–––(𝑠),𝑌–––(𝑠)=𝐶(𝑠𝐼−𝐴)−1𝐵𝑈–––(𝑠)+𝐷𝑈–––(𝑠),𝑌–––(𝑠)=(𝐶(𝑠𝐼−𝐴)−1𝐵+𝐷)𝐻(𝑠), 𝑚×𝑟𝑈–––(𝑠).

The system transfer operator relates each of the 𝑟 inputs to each of the 𝑚 outputs.

𝐻(𝑠)=𝐶(𝑠𝐼−𝐴)−1𝐵+𝐷,𝑌–––(𝑠)=𝐻(𝑠)𝑈–––(𝑠),

To invert (𝑠𝐼 −𝐴), use its determinant and adjugate:

(𝑠𝐼−𝐴)−1=1det(𝑠𝐼−𝐴)adj⁡(𝑠𝐼−𝐴).

State Space to a Block Diagram

Use one integrator for each state variable. The output of each integrator is that state variable.

For example,

𝑑𝑑𝑡[𝑥1𝑥2]=[𝑎𝑏𝑐𝑑][𝑥1𝑥2]+[𝑒𝑓][𝑢],
[𝑦]=[𝑔ℎ][𝑥1𝑥2].

State Space to an ODE

For a single output:

  1. Differentiate the output equation 𝑦 =𝐶𝑥––– +𝐷𝑢––– as many times as needed to match the system order: 𝑛 times.
  2. Differentiate the state equations ˙𝑥––– =𝐴𝑥––– +𝐵𝑢––– as many times as needed to match the system order: (𝑛 −1) times.
  3. Substitute the state equations, differentiated state equations, and output equations into the differentiated output equations until the state variables are eliminated.

Depending on the system, this can be a lot of work or very simple. Derivatives of inputs are likely to appear.

Forming an Integrator Chain

Swap the integrator and summing junction. Move the summing-junction port to the left, introducing the indicated 𝑠 block on the gain-2 input path. Move the feedback pickoff point to the left, introducing an 𝑠 block in the gain-4 feedback path. Combining the summing junctions gives an input section and an integrator-chain section.

Figure

Swap the two halves of the diagram, then move the output pickoff point to the left across the last integrator. The 𝑠 block is eliminated.

The resulting direct form has:

  • No derivatives.
  • Minimal integrators.
  • An integrator chain.

Ordinary Differential Equation

Distribute the transfer function and take the inverse Laplace transform:

𝑌(𝑠)𝑈(𝑠)=2𝑠+3𝑠2+4𝑠+5,(𝑠2+4𝑠+5)𝑌(𝑠)=(2𝑠+3)𝑈,¨𝑦+4˙𝑦+5𝑦=2˙𝑢+3𝑢.

There is no good process for this conversion directly. Convert to an ODE or block diagram first, then convert to state space.
